Introduction

Ronel is a simple and well-organized job listing Template built-in Bootstrap version 5.3.7 and Built with the latest web technologies that are HTML5, CSS3 nodejs.

Ronel contains lots of new designs of jobs pages with responsiveness on all screens. Additionally, we have given 3 different color variants, you can easily change variants in your running application. We have written minimum SCSS and codes to increase performance.

Ronel is a Job Listing Template built with developer-friendly codes and easily customizeable.

Setup

Please follow below steps to install and setup all prerequisites:

  • Node.js

    To use our build tools and take full advantage of customization options, you will need to download and install Node.js. If you do not have Node.js installed already, you can download the package installer from the official website. We recommend that you download the stable version of Node.js (LTS) to ensure the best possible experience. Download Node.js

Installation

You can run this app following package manager: Bun, Yarn or NPM

1. Bun (Recommended for mac and Linux OS)

If you don't have bun installed on your PC, use the npm i -g bun or sudo npm i -g bun to install

Command Description
bun i This would install all required dependencies node_modules folder..
bun dev Runs the project locally, starts the node development server.
bun preview It boots up a local static web server that serves the files.
2. Yarn

If you don't have yarn installed on your PC, use the yarn i -g bun or sudo npm i -g yarn to install

Command Description
yarn This would install all required dependencies node_modules folder..
yarn dev Runs the project locally, starts the node development server.
yarn preview It boots up a local static web server that serves the files.
3. NPM

npm comes preinstalled when you install Nodejs

Command Description
npm i or npm i --force This would install all required dependencies node_modules folder..
npm run preview It boots up a local static web server that serves the files.

Tips

SCSS: We suggest you not to do any changes in any scss files from public/scss/custom folders because it will trouble in future updates so we are suggesting that if you want to make any changes you can create a new custom.scss file and use that instead of the theme's file.
